# 내 페이지 템플릿 47종

바이브코딩 「내 페이지 만들기」 수업 재료입니다. 디자인을 골라 받아서 **글자만 내 이야기로 바꾸면** 소개 페이지가 됩니다.

- 골라 보기·ZIP 받기: **https://smartact.kr/workshop/vibecoding/templates**
- JavaScript 없이 HTML·CSS만 씁니다. 받아서 `index.html` 을 더블클릭하면 바로 열립니다.
- 폴더 47개가 모두 **같은 HTML 뼈대**입니다. 다른 폴더의 `style.css` 와 `DESIGN.md` 를 가져와 덮어쓰면 글은 그대로 두고 디자인만 바뀝니다.

## 폴더 하나에 들어 있는 것

| 파일 | 하는 일 |
|---|---|
| `index.html` | 글과 구조. 여기 글자만 바꿉니다 |
| `style.css` | 디자인. 맨 위 한 줄이 대표색 |
| `DESIGN.md` | 이 디자인의 규칙. AI 에게 「DESIGN.md 를 지켜」라고 하면 같은 모양으로 늘려 줍니다 |
| `images/` | 작업물 그림과 `og.jpg`(카톡으로 주소를 보낼 때 뜨는 그림) |
| `README.md` | 수강생용 사용 안내 |
| `LICENSE-design-md.txt` | 디자인 규칙 원천의 저작권 문구 |

## 받는 방법 두 가지

1. **ZIP 받기** — 위 사이트에서 디자인을 고르고 「ZIP 받기」. GitHub 계정이 없어도 됩니다.
2. **이 저장소에서 가져가기** — 초록색 **Code → Download ZIP** 으로 전체를 받고, 쓰려는 폴더 하나만 꺼내 씁니다.

내 GitHub 에 올려 Vercel 로 공개하는 방법은 수업 교재 「깃과 깃허브」 차시를 그대로 따라 하세요.

## 이용 조건

- 내 소개 페이지, 내 사업 페이지로 자유롭게 쓰세요.
- 이 템플릿 자체를 판매하거나, 남의 페이지를 만들어 주는 외주에 쓰는 것은 안 됩니다.
- 디자인 규칙(`DESIGN.md`)은 [bergside/awesome-design-skills](https://github.com/bergside/awesome-design-skills) (MIT, typeui.sh) 에서 가져와 한글 글꼴·한국어 안내를 더한 것입니다. 원 저작권 문구는 폴더마다 `LICENSE-design-md.txt` 로 함께 둡니다.
- 예시 인물(박소연·최성우·문기철 등)은 모두 지어낸 사람입니다.
